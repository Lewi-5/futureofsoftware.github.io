# futureofsoftware.github.io

A neon three.js platformer built from the talk at https://www.youtube.com/watch?v=pCh6lQ3-bgE.
Start on **Software Engineering**, then jump left through the design-engineer disciplines or right
through the system-oriented ones while the talk plays on a jumbotron in the distance.

- Run locally: `python -m http.server 8123`, then open http://localhost:8123
- Controls: WASD / arrows move · Space jump · drag to look · scroll zoom · Q/E turn · R restart · M mute
- Platform labels and blurbs live in `src/levels.js` (derived from the talk's transcript)
